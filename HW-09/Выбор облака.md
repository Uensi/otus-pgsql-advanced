### 📊 Результаты тестирования (pgbench)

Тест проводился в течение 10 секунд с 2 клиентами и 2 потоками (`pgbench -T 10 -c 2 -j 2`).

| Метрика | Yandex Cloud (Managed PG 18.4) | SberCloud (Managed PG 18.3) |
| :--- | :--- | :--- |
| **Обработано транзакций** | 3215 | 1068 |
| **Средняя задержка (Latency)**| **6.207 мс** | 18.693 мс |
| **Время начального подключения**| 27.048 мс | 35.683 мс |
| **Пропускная способность (TPS)**| **322.20** | 106.99 |
| **Ошибки** | 0 | 0 |

### Анализ производительности:
1. **Latency**: Yandex Cloud показал в **3 раза меньшую задержку** (6.2 мс против 18.7 мс), что критично для высоконагруженных OLTP-систем.
2. **Throughput (TPS)**: Пропускная способность Yandex Cloud также превосходит SberCloud более чем в 3 раза (322 TPS против 107 TPS) при одинаковых параметрах теста.
3. **Connection Time**: Инициализация соединения в Yandex Cloud происходит быстрее, что говорит о лучшей оптимизации сетевого пути или пулинга соединений (порт 6432 использует Odyssey).
