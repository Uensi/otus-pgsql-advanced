# Изменения

## 1.0.1 — 2026-10-17

- Установка без интернета: `deploy/make-wheelhouse.sh` готовит пакеты, `WHEELS=… install.sh` ставит из них.
- `install.sh` создаёт самоподписанный сертификат, если своего нет, и консоль стартует сразу.
- Инструкция по установке в WSL2 на Windows.
- Иконка вкладки; в логе больше нет 404 на `/favicon.ico`.

## 1.0.0 — 2026-10-16

Первая версия.

- Статус кластеров Patroni 4: лидер, реплики и лаг, таймлайны, pending restart, пауза; сводка etcd 3.
- Операции с проверками и контролем результата: switchover (в том числе по расписанию), failover,
  пауза, рестарт ноды, rolling restart, reinit реплики.
- Глобальный конфиг: изменение с предпросмотром и проверками, история версий, откат,
  обнаружение изменений мимо консоли.
- Наблюдатель событий с защитой от дребезга, классификация смены лидера,
  уведомления в Telegram и webhook с повторами.
- Роли viewer, operator и admin, серверные сессии, CSRF, аудит, HTTPS без внешнего веб-сервера.
- Поставка: install.sh, unit systemd с изоляцией, проверка `patroni-console-check`.
- Интеграционные тесты на живом стенде etcd 3.6 + Patroni 4 + PostgreSQL 16.

Исправлено по итогам живых прогонов (подробно в docs/TEST-REPORT.md):

- глобальный конфиг читается с лидера, а не с реплики с отстающим кэшем DCS;
- правка `patronictl edit-config` сразу после изменения из консоли больше не теряется;
- статус сразу после операции не берётся из кэша;
- падение лидера вскоре после switchover больше не принимается за этот switchover;
- LSN нод берётся из `/patroni`, раз Patroni 4.0 не отдаёт его в `/cluster`.
