## Ошибки, найденные на живом стенде и исправленные

Имитатор их не показывал. Все шесть исправлены; ошибки 2–5 закрыты модульными тестами, 1 и 6 подтверждаются живым прогоном и скриншотами.

1. **`/config` с реплики отдаёт старое значение.** Кэш DCS на реплике отстаёт до `loop_wait`. Консоль
   теперь читает конфиг сначала с лидера.
2. **Правка `edit-config` сразу после изменения из консоли терялась.** Консоль узнаёт своё изменение по
   содержимому конфига, а не по времени.
3. **Статус сразу после паузы был устаревшим.** Двухсекундный кэш статуса теперь сбрасывается
   после каждой операции.
4. **Авария вскоре после switchover могла сойти за этот switchover.** Если после падения лидера Patroni
   выбирал ту же ноду, что и недавний switchover, событие получало уровень info вместо critical.
   Теперь операция объясняет только ту смену лидера, которую сделала сама, и только одну.
5. **Колонка LSN была пустой.** Patroni 4.0 не отдаёт LSN в `/cluster`; консоль берёт его из `/patroni` каждой ноды.
6. **Баннер состояния показывал «null».** Исправлено в интерфейсе.
